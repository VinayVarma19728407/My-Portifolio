A modern, interactive developer portfolio showcasing software engineering, Artificial Intelligence and Machine Learning, and industrial data engineering projects.

Built using **React 19, TypeScript, Vite, and Modern CSS**. Designed for static deployment on **Vercel**.

**GitHub Repository:** [VinayVarma19728407/My-Portifolio](https://github.com/VinayVarma19728407/My-Portifolio)

## 🚀 Features

- **Interactive Space-Themed Interface:** Animated starfield, cosmic visuals, and space-dive transitions.
- **Typing Animations:** Typewriter effects across project, experience, certification, and skills sections.
- **Interactive Project Showcase:** Dynamic project cards with category-based filtering.
- **Instant Content Reveal:** Click interactions to immediately reveal section content.
- **Experience Timeline:** Showcases industrial internship and academic experience.
- **Certifications Showcase:** Displays professional certifications and credentials.
- **Responsive Design:** Designed to support desktop and mobile screen sizes.
- **Accessibility:** Semantic HTML, keyboard navigation, ARIA labels, and visible focus indicators.

## ⚙️ Local Development

### Prerequisites

Make sure you have installed:

- Node.js (LTS recommended)
- npm
- Git

### 1. Clone the Repository

```bash
git clone https://github.com/VinayVarma19728407/My-Portifolio.git
```

### 2. Navigate to the Project Directory

```bash
cd My-Portifolio
```

### 3. Install Dependencies

```bash
npm install
```

### 4. Start the Development Server

```bash
npm run dev
```

Open the local URL displayed in your terminal. Vite commonly uses:

```text
http://localhost:5173
```

### 5. Build for Production

```bash
npm run build
```

The production-ready files will be generated inside the `dist/` directory.

### 6. Preview the Production Build

```bash
npm run preview
```

## 🌐 Deployment on Vercel

### Option 1: Deploy through GitHub (Recommended)

1. Visit [Vercel](https://vercel.com/).
2. Sign in using your GitHub account.
3. Select **Add New → Project**.
4. Import the repository:

   `VinayVarma19728407/My-Portifolio`

5. Configure the following settings:

| Configuration | Value |
|---|---|
| Framework Preset | Vite |
| Build Command | `npm run build` |
| Output Directory | `dist` |
| Install Command | `npm install` |

6. Click **Deploy**.

Once connected, subsequent pushes to the GitHub repository can automatically trigger deployments.

### Option 2: Deploy using Vercel CLI

Install and run Vercel through:

```bash
npx vercel
```

For production deployment:

```bash
npx vercel --prod
```
